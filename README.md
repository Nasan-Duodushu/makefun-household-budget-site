Hearth & Ledger — a household budget site: one month, planned to the pound. Envelope budgeting with a working monthly plan, a transaction tracker, savings goals and charts, all computed from the same figures so they can never disagree. A static site that runs offline in the browser, on desktop and phone.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
